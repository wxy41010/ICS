# 工业控制网络安全自学指南

**Industrial Control Systems Security Self-Study Guide**

> 从理解工业系统开始，逐步掌握工业协议分析、风险评估、安全防护与实验研究。
>
> 学习主线：**理解系统 → 读懂通信 → 识别风险 → 验证防护 → 复现实验**。

本项目面向工业控制网络安全学习者，规划整理一套中文自学路线，涵盖基础知识、工业控制系统、工业通信协议、安全防护、实验实践与研究入门。希望通过有顺序的学习内容、有来源的参考资料和可复现的实验，帮助学习者建立系统性的知识框架，而不只是收集工具与链接。

**内容状态说明：** 本 README 中的章节、目录和实验为建设规划；是否已发布、是否通过验证，以仓库中的实际文件及其说明为准。

**实验边界：** 实验默认在自有或明确授权的隔离环境中开展，不连接真实生产控制网络，不控制真实执行机构。

## 适合人群

本指南适合希望进入工控安全领域的学生与研究人员、希望补充工业知识的网络安全从业者，以及希望建立网络安全基础的自动化与控制工程人员。

建议具备基本的计算机网络、操作系统和编程知识。没有工业背景的学习者，可以从设备、控制流程和工业通信开始；已有安全基础的学习者，也不建议跳过工艺过程与运行约束。

本指南将性能、可靠性和人身与过程安全作为学习 OT 安全时必须考虑的约束，而不是直接照搬传统 IT 安全方案。相关背景可参考 [NIST SP 800-82 Rev. 3](https://csrc.nist.gov/pubs/sp/800/82/r3/final)。

## 学习路线

建议按照下表顺序学习。每个阶段都应形成一份可检查的成果，再进入下一阶段。

| 阶段 | 学习重点 | 建议完成的成果 |
| --- | --- | --- |
| 01 基础准备 | TCP/IP、交换与路由、Linux/Windows 基础、Python、Git、抓包分析 | 完成一次本地通信抓包，解释连接建立与数据传输过程 |
| 02 理解工业系统 | IT/OT/ICS 概念，PLC、HMI、SCADA、DCS，传感器与执行器，控制回路，梯形图与结构化文本入门 | 绘制一个模拟控制系统的设备、数据流与控制流关系图 |
| 03 读懂工业通信 | 优先学习 Modbus TCP 与 OPC UA；按需扩展 S7、DNP3、IEC 60870-5-104、IEC 61850 | 标注一组实验通信报文，说明请求、响应及对应的控制含义 |
| 04 建立风险认知 | 资产与信任边界，威胁建模，远程运维风险，配置风险，漏洞公告分析，ATT&CK for ICS | 完成一份“资产—威胁—影响—防护措施”分析表 |
| 05 学习安全防护 | 网络分区与隔离、工业 DMZ、最小权限、访问控制、被动监测、配置备份、事件响应与恢复 | 设计一份包含访问规则、监测点与恢复步骤的防护方案 |
| 06 完成实验验证 | 隔离环境搭建、协议分析、资产梳理、规则检测、访问策略验证 | 提交可复现的实验报告、配置和脱敏证据 |
| 07 进入研究实践 | 工业异常检测、过程感知检测、告警关联、论文复现、评估方法 | 完成一个基线实验，报告结果、误差来源与适用边界 |

学习标准：不仅要知道“工具怎么用”，还要能解释“观察到了什么、为什么发生、会影响什么、怎样验证防护有效”。

## 快速开始

### 第一步：选定一个小场景

从虚拟水箱、温度监测或电机启停逻辑中选择一个**纯仿真场景**，明确输入、输出、状态变量及正常运行条件。入门阶段不要求采购真实 PLC 或工业设备。

### 第二步：搭建最小实验环境

协议实验可以从“Python + PyModbus 本地模拟服务 + Wireshark”开始；控制逻辑学习可以从 OpenPLC 编辑器及其仿真功能开始。两条路线可独立完成，后续再根据具体版本和接口进行联动。

请使用项目正式发布版本及对应文档，记录操作系统、软件版本、依赖和配置。不要默认最新开发版、不同版本教程或不同运行时能够直接兼容。

### 第三步：完成第一次可复现实验

在本机回环接口或隔离虚拟网络内，运行一个模拟 Modbus 服务和只读客户端，采集正常请求与响应，标注报文字段，并说明这些字段如何对应到模拟变量。

第一次实验的目标是**理解正常行为**，而不是扫描设备或复现攻击。

> 网络检查：不要将实验网络桥接到办公网或生产网，不要向公网开放模拟 PLC、HMI 或调试端口。需要下载依赖时，先完成准备，再切换到隔离环境开展实验。

## 实验规划

| 实验 | 内容 | 验收标准 |
| --- | --- | --- |
| Lab 01：隔离环境搭建 | 配置本地或虚拟实验网络，记录软件版本与网络边界 | 能解释实验流量可到达哪些主机，并提供隔离检查记录 |
| Lab 02：Modbus 正常通信 | 使用模拟服务与只读客户端，观察功能码、地址和返回值 | 提供正常流量样本、字段标注及变量映射说明 |
| Lab 03：控制逻辑仿真 | 编写简单启停或液位控制逻辑，仅连接模拟输入输出 | 给出正常状态变化、边界条件和逻辑测试记录 |
| Lab 04：被动监测与检测 | 对自建或获授权的离线数据进行资产梳理、通信基线分析和规则检测 | 输出资产表、通信关系、告警依据及误报分析 |
| Lab 05：防护策略验证 | 在隔离虚拟网络中配置访问规则，验证允许与拒绝行为 | 证明授权通信能够完成，非授权访问被拒绝，并保留日志 |

每个实验应包含：**实验目标、授权与隔离范围、环境版本、操作步骤、预期结果、实际结果、证据、清理或恢复方法**。

尚未运行的实验必须标注“未验证”；遇到版本不兼容、结果不一致或复现失败，应如实记录，不将教程预期结果写成实测结果。

## 研究进阶

完成基础实验后，可选择一个问题深入研究，例如工业通信异常检测、网络与过程数据联合分析、告警去重与关联、跨工况迁移、检测结果解释，或安全响应建议的辅助生成。

建议先建立简单可解释的基线，再引入复杂模型。任何模型或智能体生成的控制建议，都不应直接用于真实设备闭环执行。

**数据与评估：** 记录数据来源、版本、申请或许可条件；明确训练、验证、测试划分，避免时间窗口重叠或重复样本造成数据泄漏。阈值与超参数只使用训练集或验证集确定，不用测试集反复调优。

**结果与复现：** 报告精确率、召回率、F1、误报情况与检测延迟，并说明统计单位是采样点、时间窗口还是事件。若使用事件容忍窗口或标签后处理，须同时说明规则及其对结果的影响。

**结论与边界：** 保留基线、配置、随机种子、运行环境和失败案例；区分数据集上的实验结果与真实工业环境中的适用性，不把单一数据集上的高分等同于工程可用。

生产系统不属于本指南的默认实验范围。涉及现场验证时，应由系统负责人组织授权、风险评估、变更审批、维护窗口安排和恢复准备；不应直接将学习环境中的脚本、配置或结论用于生产系统。
